Sprint AUP — Inicio de sesión (backend)

Esta carpeta es SOLO el módulo de autenticación y gestión de usuarios.
El resto del proyecto (canchas, reservas, pagos, etc.) no debe modificarse desde aquí.

Archivos:
  routes.py         login, registro, recuperar y resetear contraseña
  admin_routes.py   listar / editar / eliminar usuarios (rol administrador)
  models.py         persona, usuario, cliente, administrador, empleado
  security.py       JWT y hash de contraseñas
  email_service.py  envío SMTP (opcional)
  config/           correo.env.example (plantilla) y correo.env (local, no se sube a GitHub)

app.py del proyecto solo registra este módulo con: from auth import register_auth
